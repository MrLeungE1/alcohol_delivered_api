<!-- 拉去项目要做的事儿 -->
- 创建数据库
- init_database() 自动执行数据库迁移
- alembic 管理数据库迁移  
   - alembic stamp head 

- 关于alembic的核心操作指令
```shell
1. 根据模型变化 自动生成迁移脚本
alembic revision --autogenerate -m '迁移描述'

2. 把迁移脚本应用到数据库(升级)
alembic upgrade head

3. 回滚到上一个版本
alembic downgrade -1
```

   1. 商品的增删改查

   1. 商品类别增删改查

   1. 管理端对活动进行增删改查

   1. 管理端对订单进行增改查 (一般情况下在管理端订单不可以被删除)

   2. 用户端可以提供删除订单的功能(但是只能删除自己的订单)
